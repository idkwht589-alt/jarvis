Secretario

Secretario es un asistente personal de uso privado. Lo utiliza únicamente su propietario y no está disponible para el público.

Política de privacidad

  • La aplicación accede a Google Calendar (y, en el futuro, a Google Tasks y Gmail) solo de la cuenta de su propietario y solo para gestionar su agenda, tareas y correo cuando él lo pide.
  • Los datos se procesan en el ordenador o servidor del propietario. No se venden, no se comparten con terceros y no se usan para publicidad.
  • Para generar respuestas, el texto de las conversaciones se envía a un proveedor de modelos de lenguaje elegido por el propietario.
  • El propietario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions.

El uso de los datos recibidos de las API de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
